# Contrato de Desarrollo Web

Documento base de ETHROVS para proyectos de diseño y desarrollo web.

## Contenido previsto

- Objeto y alcance del servicio
- Responsabilidades del cliente
- Revisiones y cambios
- Pagos y cancelaciones
- Tiempos de entrega
- Dominio, hosting y servicios externos
- Propiedad y entrega del sitio
- Soporte y mantenimiento
- Uso en portafolio
- Confidencialidad
- Limitación de responsabilidad
- Aceptación

> Este archivo será la fuente maestra del contrato. Los precios, tiempos y condiciones específicas de cada proyecto se incorporarán cuando se definan.
