# ETHROVS — Documentación

Documentación interna y comercial de ETHROVS.

## Estructura

- `legal/` — contratos, términos y acuerdos.
- `commercial/` — pagos, revisiones, cotizaciones y proceso de venta.
- `brand/` — identidad, tono y lineamientos de marca.

Los documentos finales para clientes pueden derivarse de estas fuentes internas.

## Contrato de desarrollo web

- `legal/contrato-desarrollo-web.md` — fuente maestra del Acuerdo Express de tres páginas.
- `legal/ETHROVS-Contrato-Desarrollo-Web.docx` — versión Word para sustituir los campos azules.
- `legal/ETHROVS-Contrato-Desarrollo-Web.pdf` — versión breve lista para enviar o firmar.

Antes de utilizarlo, completa todos los campos azules, especialmente la identidad legal del prestador, el alcance, precio, fechas, ley aplicable y foro. Se recomienda revisión por un abogado autorizado en la jurisdicción elegida.
